# NoBrowser Clone

A (Made with AI) minimal Android "browser" for opening links from other apps — inspired by
[rickgram/NoBrowser](https://github.com/rickgram/NoBrowser), with a few extra behaviors.

## What it does

- Opens links but won't allow editing the URL
- Does no appear in the app drawer, only in settings
- Fixes an issue that the original had with "redirection" and "open in app"  which were missing
- Back button, just in case
- hitting Android back button twice closes the app
